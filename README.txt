DAWN COLD DRINK — WORDPRESS THEME (v1.1)

WHAT'S INCLUDED
- Responsive WordPress theme using PHP templates, HTML, CSS and vanilla JavaScript.
- Homepage sections: Hero, Products, About Us, Why Dawn, Gallery, Contact form.
- Mobile navigation, sticky header, smooth scrolling, subtle hover effects.
- CSS product cans and gallery placeholders (replace with real photography when available).
- Contact form with nonce protection and wp_mail handler (configure SMTP for delivery).

INSTALLATION
1. Zip the 'dawn-cold-drink' folder.
2. WordPress Admin → Appearance → Themes → Add New → Upload Theme → Activate.
3. Settings → Reading → Your homepage displays → A static page (optional if front-page.php is used).
4. Update sample product names, email, phone and social links with real brand details.
5. Replace gradient gallery placeholders with approved product/lifestyle images.
6. Configure an SMTP plugin so the contact form can deliver mail reliably.

SECTIONS
- Hero (#) – branding, headline, CTA, CSS can illustration
- Products (#flavours) – three sample flavours with product-can visuals
- About (#about) – mission & vision
- Why Dawn (#why) – four brand highlights
- Gallery (#gallery) – six lifestyle placeholders
- Contact (#contact) – enquiry form + details
- Footer – logo, nav, social, copyright

NOTES
- No external libraries or plugins required for basic function.
- Do not invent certifications, nutrition claims or health benefits.
- Theme activates cleanly; form works after mail configuration.
