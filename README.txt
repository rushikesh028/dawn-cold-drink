## 🌅 About The Project

**Dawn Cold Drink** is a modern and visually engaging WordPress website theme developed for a beverage brand seeking a strong digital presence.

The website combines an attractive user interface, responsive layouts, product showcases, and interactive elements to deliver a smooth browsing experience.

Built using PHP, HTML5, CSS3, and Vanilla JavaScript, the theme follows a lightweight development approach without requiring external frontend frameworks.

The primary objective is to establish brand identity, showcase beverage products, and encourage customer enquiries through an engaging digital platform.

## ✨ Key Features

- Modern and attractive beverage brand design.
- Fully responsive desktop, tablet, and mobile layouts.
- Interactive homepage with a dedicated hero section.
- Product showcase featuring sample beverage flavours.
- Custom CSS-based beverage can illustrations.
- Dedicated About Us and brand storytelling sections.
- Why Dawn brand highlights.
- Product and lifestyle image gallery.
- Customer enquiry contact form.
- Sticky header and mobile navigation.
- Smooth scrolling and subtle hover animations.
- WordPress-integrated email functionality.
- Secure contact form request verification.

## 📂 Project Structure

The theme follows a modular WordPress structure with separate template, styling, scripting, and asset resources.

- **assets/css/** – Website styling.
- **assets/js/** – Interactive functionality.
- **assets/images/** – Image resources.
- **functions.php** – Theme setup and functionality.
- **style.css** – Theme metadata and styling.
- **front-page.php** – Homepage template.
- **header.php** – Website header and navigation.
- **footer.php** – Footer layout.
- **index.php** – Main theme template.
- **page.php** – Standard page template.

## ⚙️ Installation Guide

### WordPress Dashboard Installation

1. Download the Dawn Cold Drink theme.
2. Compress the theme folder into a ZIP file.
3. Open your WordPress Admin Dashboard.
4. Navigate to **Appearance → Themes**.
5. Select **Add New → Upload Theme**.
6. Upload the theme ZIP file.
7. Click Install Now.
8. Activate the Dawn Cold Drink theme.

### Manual Installation

1. Extract the downloaded theme folder.
2. Open your WordPress installation directory.
3. Navigate to the themes directory.
4. Upload the Dawn Cold Drink folder.
5. Open WordPress Admin Dashboard.
6. Navigate to Appearance → Themes.
7. Activate the theme.
